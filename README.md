# MooManager

Sistema fullstack de gerenciamento de rebanho, desenvolvido com **Spring Boot** no backend e **HTML, CSS e JavaScript** no frontend, focado no controle de produção, reprodução e autenticação de usuários.

---

##  Sobre o Projeto

O **MooManager** é uma aplicação que auxilia no gerenciamento de propriedades rurais, permitindo o controle completo de:

- Cadastro de animais
- Dados de reprodução
- Produção (ex: leite)
- Autenticação de usuários
- Histórico detalhado por animal

O sistema foi projetado com arquitetura em camadas e comunicação via API REST.

---

##  Tecnologias Utilizadas

###  Backend
- Java
- Spring Boot
- Spring Data JPA
- Spring Security
- JWT (JSON Web Token)

###  Frontend
- HTML
- CSS
- JavaScript (Vanilla)

### Banco de Dados
- PostgreSQL
